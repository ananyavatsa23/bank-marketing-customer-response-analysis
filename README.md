# Bank Marketing Campaign & Customer Response Analysis
Objective: Identify customer and campaign characteristics associated with term-deposit subscription and identify higher-potential customer segments.
Dataset: 45,211 customers
Tools: Python | PostgreSQL | Power BI
Methods: EDA | Hypothesis Testing | Logistic Regression | Customer Segmentation | Predictive Modelling
Model Performance: ROC-AUC 0.753 | Recall 68.2%
Business Output: Customer targeting insights + Power BI campaign dashboard
